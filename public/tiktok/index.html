Fizmatix Riyaziyyat

Fizmatix Riyaziyyat is a small educational studio by a mathematics teacher from Azerbaijan. Every day it prepares short vertical videos with one school math problem (DİM / final-exam style): the problem, a few seconds to think, the step-by-step solution and the answer, voiced in Azerbaijani.

The app connects to the teacher's own TikTok account @fizmatix.riyaziyyat with Login Kit and uses the Content Posting API to publish these ready videos twice a day (07:30 and 18:30, Baku time) with a short caption. It does not access any other accounts, does not read users' data and does not collect personal information of viewers.

Each video links to an interactive version of the same problem: sual.fizmatix.com.
