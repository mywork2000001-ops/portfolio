# Промт-ТЗ: портфолио-сайт «Orbit»

> Этот файл — самодостаточный промт для AI-кодера (или для себя самого при «вайб-кодинге»).
> Скопируй его целиком в новый чат/агент, приложи `Maket.png` и `foto.png` — и получишь тот же результат,
> который уже реализован в этом репозитории.

## 1. Роль и цель

Ты — senior frontend-разработчик. Нужно верстать одностраничное (SPA, скролл-секции) портфолио
Fullstack-разработчика **«Ферид Г.»** под брендом **Orbit**, пиксель-близко к приложенному макету
`Maket.png`. Фото автора — `foto.png` (использовать в секции «Обо мне»).

Результат — рабочий фронтенд-проект, который запускается локально (`npm run dev`) и визуально
соответствует макету в light- и dark-теме.

## 2. Стек

- Vite + React 18 + TypeScript
- Tailwind CSS (утилитарные классы, без CSS-in-JS)
- lucide-react — иконки
- Без бэкенда, без роутера (одна страница, якорный скролл по секциям)
- Тема (light/dark) — через `data-theme`/класс на `<html>` + `localStorage`, переключатель в шапке

## 3. Дизайн-токены

**Цвета**
- Сайдбар: всегда тёмный, независимо от темы — фон `#0B0B14`, текст `#B4B4C7`, активный пункт —
  пилюля с фоном `#6C5CE7`/20% и текстом `#FFFFFF`
- Акцентный градиент (основная CTA-кнопка, аватар-рамка, активные элементы): `#6C5CE7 → #4E7FFF`
  (indigo → blue), угол ~135deg
- Light-тема (контент): фон `#F5F6FA`, карточки `#FFFFFF`, текст `#14141F`, вторичный текст `#6B6B80`
- Dark-тема (контент): фон `#0F0F1A`, карточки `#181826`, текст `#F2F2F7`, вторичный текст `#8B8BA0`
- Тени карточек: мягкие, `0 8px 24px rgba(0,0,0,0.06)` (light) / `rgba(0,0,0,0.4)` (dark)
- Радиусы: 16px у карточек, 12px у кнопок/бейджей, 999px у пилюль и круглых иконок

**Типографика**
- Шрифт: Inter / system-ui sans-serif
- Имя в hero — крупный градиентный текст (clip на фон-градиент), 40–48px, bold
- Заголовки секций — 20–24px, semibold
- Тело — 14–15px, обычный

**Иконки тех-стека (цветные бейджи в разделе «Навыки»)**
HTML5 (оранж), CSS3 (синий), JavaScript (жёлтый), TypeScript (синий), React (голубой),
Node.js (зелёный), MongoDB (зелёный тёмный), PostgreSQL (синий тёмный), Git (оранж)

## 5. Поведение и интерактивность

- Клик по пункту сайдбара — плавный скролл (`scroll-behavior: smooth`) к секции + подсветка
  активного пункта по текущей секции в вьюпорте (IntersectionObserver)
- Переключатель темы — мгновенно меняет CSS-переменные/класс, сохраняет выбор в `localStorage`,
  по умолчанию — системная тема
- Все интерактивные элементы — доступны с клавиатуры, видимый `:focus-visible`
- Карточки проектов/скиллов — лёгкий hover (подъём/тень), без блокирующих анимаций
- Мобильная адаптивность: брейкпоинты `sm/md/lg`, сайдбар → верхний бар с выпадающим меню

## 6. Критерии готовности

- [ ] Верстка визуально соответствует `Maket.png` в развёрнутом состоянии на десктопе
- [ ] Light и dark темы обе выглядят цельно (не «недоделанная» тема)
- [ ] Адаптивность 375px–1920px без горизонтального скролла
- [ ] Все тексты — из раздела 4 (реальный контент, не lorem ipsum)
- [ ] `npm run dev` поднимает проект без ошибок в консоли
- [ ] Нет захардкоженных секретов/аналитики/трекеров

## 7. Вне рамок (не делать)

- Не подключать бэкенд/формы отправки (кнопка «Связаться со мной» — просто якорь на контакты)
- Не тащить реальные скриншоты проектов — только абстрактные CSS/SVG-превью (проекты в карточках
  реальные, но превью — стилизованная заглушка, не скриншот)
- Не добавлять лишние страницы/роутинг — это одностраничник
